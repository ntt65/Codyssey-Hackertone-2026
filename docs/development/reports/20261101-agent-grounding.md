백엔드의 발화 근거·시각 검증 1단계를 구현했습니다. 모델이 말하지 않은 출발지나 발화와 다른 날짜·시각을 제안하면 보류하고, 모호한 시각이나 시작·종료 대상을 임의로 확정하지 않도록 했습니다. 세 공급자에 공통 검증을 연결했습니다.

백엔드 테스트 111개와 도구 테스트 26개가 통과했습니다. 전체 하네스는 기존 연락처 테스트와 문화정보 테스트의 docstring 누락 7건으로 실패했습니다. 세 공급자는 모의 응답으로 검증했으며 실제 모델 호출과 화면·음성 검증은 하지 않았습니다.

시각 검증은 보수적입니다. 예를 들어 “오후 2시부터 5시까지”는 두 번째 시각의 오전·오후를 확인해야 합니다. 요일·상대 시각 등 일부 표현도 보류합니다. 출발지와 목적지의 의미, 일반 선호 해석은 원문 인용만으로 완전히 검증할 수 없습니다.

프론트는 수정하지 않았습니다. 현재 화면은 서버의 보류 안내를 충분히 소비하지 않고 오류 시 자체 규칙 해석으로 전환할 수 있어, 이번 변경만으로 화면에서 모든 잘못된 확정이 차단된다고 보장할 수 없습니다. 재질문 표시, 조건 전달·변경 동의, 늦은 응답 처리, 추천 순위 유지에 관한 [프론트 담당자 개선안](/D:/git/lab678/plan_dj/frontend-agent-improvements-20261101.md)을 작성했습니다.
